Креирање директориум и иницијализација на Git
mkdir SI_2025_lab1_233248
cd SI_2025_lab1_233248
git init

Поврзување со GitHub репозиториум
git remote add origin https://github.com/mateailieska/SI_2025_lab1_233248.git

Креирање на README.md
echo "Matea Ilieska 233248" > README.md
git add README.md
git commit -m "Initial commit"


Креирање на Java фајл
nano SI2025Lab1Main.java

Откако ќе се внесе кодот:
git add SI2025Lab1Main.java
git commit -m "Add starter code"
git push origin master

git fetch origin
